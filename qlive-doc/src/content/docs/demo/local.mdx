The view below is `grid/Local` from qlive-test, unchanged, running in your
browser on data recorded from the running application.

The view injects every user at once and hands the rows to `useLocalDocument()`.
That document answers `update()` from its rows, with the same conditions a
query would send to the server, so the grid can't tell the difference. In the
application this grid is the one that never asks the server; on this page,
none of them do.
