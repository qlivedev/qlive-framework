# @qlivedev/qlive-ts

The client half of [QLive](https://qlivedev.github.io/qlive-framework/), a full-stack framework for React, Spring Boot and jOOQ.
It works together with the `qlive` Maven artifacts on the server.

**[User documentation](https://qlivedev.github.io/qlive-framework/)**
