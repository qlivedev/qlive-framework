# @qlivedev/qlive-codegen

Build-time code generation for [QLive](https://qlivedev.github.io/qlive-framework/): the TypeScript types of an application's domain
and queries, from its GraphQL schema. Used together with
[`@qlivedev/qlive-ts`](https://www.npmjs.com/package/@qlivedev/qlive-ts).

**[User documentation](https://qlivedev.github.io/qlive-framework/)**

- [Regenerate from the schema](https://qlivedev.github.io/qlive-framework/how-to/regenerate-from-the-schema/)
- [Generated artifacts](https://qlivedev.github.io/qlive-framework/reference/generated-artifacts/)
